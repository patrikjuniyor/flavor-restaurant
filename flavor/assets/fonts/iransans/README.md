# IRANSans (optional)

IRANSans is a commercial typeface (Fontiran). It is **not** bundled with Flavor.

If you have a valid redistribution license, drop the `woff2` files here:

- `IRANSans.woff2`
- `IRANSans-Medium.woff2`
- `IRANSans-Bold.woff2`

`assets/css/fonts.css` already declares the family. The theme keeps Vazirmatn (OFL) as the default.
