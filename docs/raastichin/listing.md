# متن لیستینگ راست‌چین — رستوران مستقیم

## عنوان

رستوران مستقیم | قالب + افزونه سفارش‌گیری کافه و رستوران (QR، آشپزخانه، رزرو شمسی)

## چکیده کوتاه

سفارش سالن با QR، بیرون‌بر و ارسال، داشبورد آشپزخانه، رزرو شمسی، ورود با موبایل و تومان — بدون وابستگی به فونت گوگل و سرویس خارجی.

## توضیح بلند

رستوران مستقیم برای کافه، فست‌فود، رستوران سنتی، شیرینی‌فروشی، آبمیوه‌فروشی، کترینگ و آشپزخانه ابری ساخته شده است.

- قالب `flavor` فقط ظاهر و هشت دمو است.
- افزونه `flavor-core` سفارش، شعبه، میز، آشپزخانه و رزرو را نگه می‌دارد؛ با عوض کردن قالب داده از بین نمی‌رود.

ویژگی‌ها: منوی موبایل‌اول، شیت مدیفایر، سه حالت سفارش، درگاه‌های ووکامرس (زرین‌پال و …)، پرداخت پای صندوق، OTP موبایل، پیامک ایرانی، منطقه ارسال، رزرو جلالی، باشگاه مهر و امتیاز، سفارش تلفنی.

هشت دمو یک‌کلیکی با آیتم‌های فارسی و قیمت تومان.

## سازگاری

وردپرس ۶.۴+ / ووکامرس ۸.۵+ / PHP ۸.۰+ / RTL / ووکامرس HPOS

## واژه‌های کلیدی

قالب رستوران، سفارش آنلاین غذا، منو QR، ووکامرس رستوران، رزرو میز شمسی، داشبورد آشپزخانه
