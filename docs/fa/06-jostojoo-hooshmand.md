# جست‌وجوگر هوشمند منو (AJAX)

از نسخه **۱.۱.۰** صفحهٔ «منوی سفارش» یک جست‌وجوی زندهٔ AJAX دارد: مشتری تایپ می‌کند و بدون بارگذاری صفحه نتیجه می‌بیند.

## چه چیزی هوشمند است؟

| قابلیت | مثال |
|---|---|
| یکسان‌سازی حروف عربی/فارسی | «كباب كوبيده» = «کباب کوبیده» |
| ارقام فارسی و عربی | «۲ سیخ» = «2 سیخ» |
| حذف اعراب، کشیده و نیم‌فاصله | «قُرمه‌سبزی» = «قرمه سبزی» |
| ریشه‌یابی سبک | «نوشیدنی‌ها» → «نوشیدنی» |
| تحمل غلط املایی (Levenshtein) | «کبیده» → «کوبیده» |
| حذف کلمات بی‌اثر | «می‌خوام یک پیتزا» → «پیتزا» |
| «منظورتان این بود؟» | وقتی نتیجه‌ای نیست، نزدیک‌ترین نام پیشنهاد می‌شود |
| پرجست‌وجوها | عبارت‌های پرتکرار مشتری‌ها |
| جست‌وجوهای اخیر | در localStorage مرورگر مشتری |

## رتبه‌بندی نتایج

امتیاز هر آیتم از این سیگنال‌ها ساخته می‌شود:

| سیگنال | وزن |
|---|---|
| نام دقیقاً برابر عبارت | ۱۲۰ |
| عبارت داخل نام | ۷۰ |
| توکن نام برابر | ۴۰ |
| توکن نام با همان پیشوند | ۳۰ |
| تطبیق فازی (غلط املایی) | تا ۲۴ |
| نام دسته‌بندی | ۱۶ |
| برچسب | ۱۲ |
| توضیحات | ۵ تا ۸ |

سپس ضرایب اعمال می‌شود: ناموجود ×۰٫۴۵، خارج از بازهٔ سرو ×۰٫۷، پوشش کامل همهٔ کلمات ×۱٫۲۵، به‌علاوهٔ امتیاز محبوبیت (`total_sales`) و میانگین امتیاز محصول.

## اندپوینت‌ها

```
GET /wp-json/flavor/v1/search?q=کباب&branch_id=12&limit=8
GET /wp-json/flavor/v1/search/suggest?q=کبا
GET /wp-json/flavor/v1/search/popular
```

پارامترهای `search`:

| پارامتر | نوع | توضیح |
|---|---|---|
| `q` | string | عبارت جست‌وجو (خالی = حالت مرور بر اساس محبوبیت) |
| `branch_id` | int | شعبه؛ خالی یعنی شعبهٔ پیش‌فرض |
| `limit` | int | حداکثر ۳۰ |
| `category` | int | فیلتر دستهٔ ووکامرس |
| `dietary` | string | فهرست جداشده با ویرگول، مثل `vegan,gluten_free` |
| `min_price` / `max_price` | int | به واحد ذخیره‌سازی (تومان/ریال) |
| `available` | bool | فقط آیتم‌های موجود |

نمونهٔ پاسخ:

```json
{
  "query": "کبیده",
  "total": 3,
  "results": [
    {
      "id": 41,
      "name": "کباب کوبیده",
      "highlight": "کباب <mark>کوبیده</mark>",
      "price_html": "۱۸۵٬۰۰۰ تومان",
      "available": true,
      "score": 61.2
    }
  ],
  "facets": { "categories": [], "dietary": [], "price": { "min": 0, "max": 0 } },
  "suggestion": "",
  "popular": []
}
```

**سازگاری با کش:** برای سایت‌هایی که REST را می‌بندند یا صفحه را کامل کش می‌کنند، مسیر جایگزین
`admin-ajax.php?action=flavor_search&q=...` همان خروجی را داخل `{success, data}` برمی‌گرداند.

## امنیت و کارایی

- محدودسازی نرخ: ۹۰ درخواست در دقیقه برای هر IP (`RateLimit`)، پیشنهادها ۱۲۰ در دقیقه.
- ایندکس محصولات در ترنزینت `flavor_search_idx_{branch}` با عمر ۱۵ دقیقه کش می‌شود و با ذخیرهٔ محصول، تغییر دسته یا تغییر موجودی خودکار پاک می‌شود.
- خروجی `highlight` سمت سرور با `esc_html` امن‌سازی می‌شود و فقط `<mark>` اضافه می‌کند؛ سمت کلاینت هم دوباره اعتبارسنجی می‌شود.
- `Cache-Control: public, max-age=30` روی پاسخ جست‌وجو.
- هیچ کتابخانهٔ خارجی یا CDN اضافه نشده است؛ فقط ~۹ کیلوبایت جاوااسکریپت ساده.

## تجربهٔ کاربری

- دیبانس ۲۲۰ میلی‌ثانیه و لغو درخواست قبلی با `AbortController`.
- کش درون‌حافظه‌ای برای عبارت‌های تکراری.
- ناوبری با کیبورد: `↑` `↓` `Enter` `Esc` و میان‌بر `Ctrl/⌘ + K`.
- دسترس‌پذیری: الگوی `combobox` + `listbox`، `aria-activedescendant`، `aria-live`.
- هم‌زمان با نمایش نتایج، گرید منو هم به همان آیتم‌ها محدود می‌شود.
- بدون جاوااسکریپت، فرم به جست‌وجوی پیش‌فرض وردپرس ارسال می‌شود.

## قلاب‌های توسعه‌دهنده

| قلاب | نوع | کاربرد |
|---|---|---|
| `flavor_core_search_index_limit` | filter | سقف تعداد محصولات ایندکس (پیش‌فرض ۵۰۰) |
| `flavor_core_search_documents` | filter | افزودن/حذف سند از ایندکس |
| `flavor_core_search_response` | filter | دستکاری پاسخ نهایی |
| `flavor_core_search_popular_fallback` | filter | عبارت‌های پیشنهادی پیش‌فرض |
