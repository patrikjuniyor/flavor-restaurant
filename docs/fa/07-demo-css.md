# لایهٔ هنری و حرکتی CSS برای دموهای Flavor

این بازبینی برای هر ۱۲ دمو یک امضای دیداری مستقل در فایل CSS همان دمو اضافه می‌کند. هیچ عکس تازه‌ای تولید یا دانلود نشده است؛ عکس‌های فعلی سایت/دمو دست‌نخورده‌اند و نقش اصلی طراحی را هندسه، رنگ، حاشیه، سایه و گرادیان‌های CSS دارند.

| دمو | امضای دیداری CSS |
|---|---|
| رستوران مدرن (`modern-restaurant`) | چیدمان تحریریه‌ای، ریل باریک زعفرانی و کارت‌های سرامیکی نامتقارن |
| رستوران لوکس (`luxury-dining`) | قاب ظریف شامپاینی، زمینهٔ شبانه و کارت‌های شبیه قاب گالری |
| سنتی ایرانی (`persian-traditional`) | حاشیه‌های هندسی الهام‌گرفته از کاشی، با ترکیب فیروزه‌ای، زرشکی و برنجی |
| کافه و بیسترو (`cafe-bistro`) | حس کاغذ کرم و قهوه، جداکننده‌های خط‌چین و کارت‌های گرمِ پیشخوان |
| فست‌فود (`fast-food`) | پنل‌های پوستر خیابانی، برچسب‌های چرخیده و سایه‌های جوهریِ پُرکنتراست |
| ایتالیایی و پیتزا (`pizza-italian`) | لبهٔ سه‌رنگ، فرم‌های گرمِ تراتوریا و حاشیه‌های سبز/گوجه‌ای |
| نانوایی و شیرینی (`bakery-pastry`) | فرم‌های قوسی لطیف، صورتی ماکارونی و سبز پسته‌ای |
| آبمیوه (`juice-bar`) | برش مرکبات ساخته‌شده با گرادیان‌های CSS و رنگ برگ/لیمو |
| دارک لوکس (`dark-luxe`) | قاب مسیِ ظریف روی زمینهٔ مشکی و جزئیات کم‌نور |
| مینیمال (`minimal-clean`) | قاب‌بندی گالری سفید، خط‌های دقیق و بدون تزئین اضافه |
| آشپزخانه ابری (`cloud-kitchen`) | شبکهٔ نقشه/بلوپرینت، نقطه‌مسیرهای لیمویی و پنل عملیاتی |
| کترینگ (`catering`) | خطوط رسمی برنجی، پنل پیشنهاد اختصاصی و حالت فوکوس روشن برای فرم |

## لایهٔ حرکتی (انیمیشن)

هر ۱۲ دمو یک بلوک «Motion art direction» اختصاصی در انتهای فایل CSS خود دارد. این بلوک سه چیز اضافه می‌کند: توکن‌های زمان‌بندی همان دمو، `@keyframes` اختصاصی آن، و قواعد ورود/هاور که فقط با آن پوسته فعال می‌شوند.

| دمو | امضای حرکتی | نمونهٔ کلیدواژه‌ها |
|---|---|---|
| رستوران مدرن (`modern-restaurant`) | تایپ مثل چاپ: عنوان با ماسک بالا می‌آید، خط زعفرانی زیر برچسب بخش کشیده می‌شود، یک درخشش گرم روی کارت | `flavor-m-mr-mask`، `flavor-m-mr-rule`، `flavor-m-mr-sheen` |
| رستوران لوکس (`luxury-dining`) | کند و شامپاینی، بدون هیچ پرش: خط طلا روی عنوان، سوسوی شمع‌وار پس‌زمینهٔ شب، کارت‌ها «روشن» می‌شوند نه «بلند» | `flavor-m-lx-gilt`، `flavor-m-lx-candle`، `flavor-m-lx-vignette` |
| سنتی ایرانی (`persian-traditional`) | هندسه در حرکت: آیکون مثل کاشی گره می‌چرخد، برچسب بخش بین لاجوردی/زرشکی/برنجی جابه‌جا می‌شود، حاشیه از مرکز باز می‌شود | `flavor-m-pt-girih`، `flavor-m-pt-glaze`، `flavor-m-pt-unroll` |
| کافه و بیسترو (`cafe-bistro`) | کاغذ و بخار: کارت مثل زیرلیوانی بلند می‌شود، بخار روی غذای گرم، عکس‌های گالری با شیب کوچک سنجاق می‌شوند | `flavor-m-cb-steam`، `flavor-m-cb-chalk`، `flavor-m-cb-pin-a` |
| فست‌فود (`fast-food`) | انرژی پوستری: عنوان کوبیده می‌شود، برچسب‌ها می‌لرزند، کارت‌ها با سایهٔ جوهری سخت پاپ می‌شوند (تنها دمویی که پرش فنری دارد) | `flavor-m-ff-slam`، `flavor-m-ff-wobble`، `flavor-m-ff-pop` |
| ایتالیایی و پیتزا (`pizza-italian`) | سه‌رنگ به‌عنوان ترنزیشن: نوار سبز-سفید-قرمز روی کارت، خمیر با نرمی ور می‌آید، برگ ریحان تاب می‌خورد | `flavor-m-pi-dough`، `flavor-m-pi-sway`، `flavor-m-pi-toss` |
| نانوایی و شیرینی (`bakery-pastry`) | خیز نرم و لهیدگی ملایم: کارت مثل سوفله بالا می‌آید، دکمه مثل ماکارون فشرده می‌شود، پاشیدنی‌های پاستلی | `flavor-m-bp-souffle`، `flavor-m-bp-squish`، `flavor-m-bp-sprinkle` |
| آبمیوه (`juice-bar`) | مایع: پر شدن قوسی هیرو با گرادیان مرکبات، حباب در نوار تازگی، تاب خوردن مهر تازگی روی پین خودش | `fd-m-jb-fill`، `fd-m-jb-bubble`، `fd-m-jb-swing` |
| دارک لوکس (`dark-luxe`) | سینما: نوارهای لترباکس روی کادر هیرو، یک عبور نور مسی روی هر قاب، دانه‌بندی فیلم | `fd-m-dl-letterbox`، `fd-m-dl-sweep`، `fd-m-dl-grain` |
| مینیمال (`minimal-clean`) | دقت: یک خط مویی، یک پلهٔ شفافیت، بدون هیچ چرخش یا مقیاس — ساکت‌ترین لایهٔ دوازده‌گانه | `fd-m-mc-hairline`، `fd-m-mc-rule`، `fd-m-mc-fade` |
| آشپزخانه ابری (`cloud-kitchen`) | کنسول عملیاتی که بالا می‌آید: شبکهٔ بلوپرینت رسم می‌شود، نقطهٔ مسیر حرکت می‌کند، خط اسکن روی پنل | `fd-m-ck-plot`، `fd-m-ck-route`، `fd-m-ck-scan` |
| کترینگ (`catering`) | پروندهٔ رسمی: خط برنجی باز می‌شود، پنل‌ها به ترتیب می‌آیند، مهر در پایان فشار داده می‌شود | `fd-m-ct-brass`، `fd-m-ct-seal`، `fd-m-ct-rule` |

### دو لایهٔ مشترک

- `assets/css/motion.css` + `assets/js/motion.js` — لایهٔ مشترک واژگان `flavor-*`: چیدمان هفت دموی کلاسیک، و همهٔ سطح‌های تجاری که هر ۱۲ پوسته رندر می‌کنند (منو، سبد، رزرو، حساب، پیگیری سفارش). همچنین سطح‌هایی که **بعد از** اولین پاس انیمیشن اضافه شدند: داک شناور، مگا‌منو، کلید حالت شب، فیلترهای منو، علاقه‌مندی‌ها، نمای سریع، نوار رضایت، پاپ‌آپ و شمارش معکوس.
- `assets/css/demo-animations.css` + `assets/js/demo-animations.js` — لایهٔ پنج دموی اختصاصی با واژگان `fd-*` (نسخهٔ ۱.۱.۰).

### قرارداد اجرا

- **هیچ‌چیز پیش از تأیید جاوااسکریپت پنهان نمی‌شود.** هر قاعده‌ای که می‌تواند محتوا را پنهان یا جابه‌جا کند، پشت کلاس `html.flavor-anim-ready` (یا `html.fd-anim-ready` در دموهای اختصاصی) قرار دارد که اسکریپت آن را در زمان اجرا می‌گذارد. اگر اسکریپت اجرا نشود، بلاک شود یا خطا بدهد، صفحه دقیقاً مثل قبل رندر می‌شود.
- **انیمیشن چیدمان را تعیین نمی‌کند.** فقط `transform`، `opacity`، `filter` و `background-position` متحرک می‌شوند؛ هیچ ورودی نمی‌تواند بخشی را از ویوپورت بیرون ببرد (آزمون `tests/ui/responsive.mjs`).
- **زمان‌بندی درست:** عناصر بالای صفحه با `html.*-anim-ready` بازی می‌شوند؛ هر چیزی داخل یک بخش، به `.flavor-anim-in` نیاکان خود گره خورده تا وقتی کاربر به آن اسکرول کرد اجرا شود، نه در لحظهٔ بارگذاری.
- **کاهش حرکت، زنده بررسی می‌شود.** اگر کاربر تنظیم سیستم را وسط نشست عوض کند، اسکریپت خودش را جمع می‌کند و صفحه ساکن می‌شود، بدون رفرش.
- در همهٔ بلوک‌ها `@media (prefers-reduced-motion: reduce)` با سلکتورهای واقعی همان فایل نوشته شده و هیچ `font-size` زیر ۱۲ پیکسل اضافه نشده است.

## پیاده‌سازی

- هر دمو در `flavor/assets/css/skins/{slug}.css` باقی می‌ماند؛ قواعد فقط با کلاس `body.flavor-skin-{slug}` محدود شده‌اند.
- دموهای پنج‌گانهٔ اختصاصی، علاوه بر پوستهٔ مشترک، از کلاس‌های مستقل `.fd-*` خود استفاده می‌کنند.
- عناصر تزئینی با pseudo-element و گرادیان CSS ساخته شده‌اند؛ دریافت فونت/CDN یا asset تازه لازم نیست.
- چیدمان‌های موبایل حفظ شده‌اند. قاب‌ها و بافت‌ها `pointer-events: none` دارند تا دکمه‌ها و لینک‌ها را نپوشانند.
- در ریزنویسی‌های کترینگ، زیرنویس‌های واقعی از ۱۲ پیکسل کمتر نمی‌شوند؛ فوکوس ورودی‌های برنامه‌ریز هم حلقهٔ واضح دارد.

برای بررسی سریع overflow و حداقل اندازهٔ متن/هدف لمسی، آزمون standalone زیر CSSهای واقعی دوازده پوسته را در ۹ عرض مرور می‌کند:

```bash
cd tests/ui
npm ci
node responsive.mjs
```

برای بررسی خود لایهٔ حرکتی — اینکه هر پوسته بلوک خودش را دارد، هر `animation` به یک `@keyframes` موجود اشاره می‌کند، هر شیت متحرک گارد کاهش حرکت دارد، هیچ قاعده‌ای بی‌گیت محتوا را پنهان نمی‌کند و پارالاکس/تیلت با هم تصادم ندارند — این آزمون بدون مرورگر و بدون وردپرس اجرا می‌شود:

```bash
cd tests/ui
node motion.mjs
```

همین آزمون در CI هم اجرا می‌شود: job مستقل `motion-layer-guard` در
`.github/workflows/ci.yml` با Node 20، روی هر push به `main` و هر pull request.
هیچ مرورگر و هیچ وردپرسی لازم نیست، پس چند ثانیه بیشتر طول نمی‌کشد و ماتریس PHP را
هم بی‌دلیل چهار برابر نمی‌کند.
