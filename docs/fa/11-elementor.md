# Elementor در Flavor

Flavor در صورت فعال بودن Elementor، **۱۷ ویجت** اختصاصی در دسته‌ای با نام «رستوران مستقیم — Flavor» و **سه قالب آمادهٔ صفحه** در اختیار شما می‌گذارد.

## پیش‌نیاز و نصب صحیح

- Flavor یک **پوسته** است و افزونهٔ Elementor را همراه خود نصب نمی‌کند؛ افزونهٔ رسمی **Elementor Website Builder** را از «افزونه‌ها ← افزودن» نصب و فعال کنید. نسخهٔ رایگان برای ویجت‌های Flavor کافی است؛ Elementor Pro لازم نیست.
- پوستهٔ **Flavor** را فعال کنید. این مخزن یک monorepo است؛ فایل ZIP اصلی GitHub را به وردپرس ندهید. فقط پوشهٔ `flavor/` یا بستهٔ ساخته‌شدهٔ `dist/flavor.zip` پوسته است.
- یک برگه بسازید و **ویرایش با Elementor** را بزنید. در پنل ویجت‌ها دستهٔ «رستوران مستقیم — Flavor» را باز کنید یا نامی مثل `flavor_menu` را جست‌وجو کنید.

### اگر ویجت‌ها در پنل دیده نمی‌شوند

1. در **افزونه‌ها ← افزونه‌های نصب‌شده** مطمئن شوید Elementor فعال است؛ Flavor Core جای Elementor را نمی‌گیرد.
2. در **نمایش ← پوسته‌ها** مطمئن شوید پوستهٔ Flavor فعال است و پوشهٔ نصب‌شده `flavor` است، نه پوشهٔ ریشهٔ `flavor-restaurant`.
3. صفحه را دوباره با **ویرایش با Elementor** باز و پنل ویجت‌ها را تازه‌سازی کنید؛ سپس کش افزونه/مرورگر را پاک کنید.
4. از نسخهٔ تازهٔ پوسته استفاده کنید. در نسخهٔ **1.6.2** ترتیب بارگذاری دستهٔ Flavor اصلاح شده و یک تست رگرسیون، ثبت دسته را پیش از بارگذاری ویجت‌ها بررسی می‌کند.
5. اگر در صفحهٔ نخست از Elementor استفاده می‌کنید، در نسخهٔ **1.6.2** بررسی متادادهٔ Elementor (`_elementor_data`) اضافه شده تا حتی در صورت خالی بودن محتوای خام متن وردپرس، طرح و بخش‌های ساخته‌شده با Elementor بدون مشکل رندر شوند.

## ویجت‌ها

| ویجت (نام داخلی) | کار |
|---|---|
| `flavor_hero` | بخش اصلی صفحه (عنوان، متن، دکمه، تصویر) |
| `flavor_about` | داستان ما |
| `flavor_gallery` | گالری تصاویر |
| `flavor_testimonials` | نظرات مهمان (لیست تکرارشونده) |
| `flavor_branch_info` | اطلاعات شعبه |
| `flavor_menu` | منوی غذا از محصولات ووکامرس |
| `flavor_reservation` | بخش رزرو |
| `flavor_hours` | ساعات کاری (هر روز در یک ردیف) |
| `flavor_order_cta` | دعوت به سفارش |
| `flavor_offers` | پیشنهاد ویژه با کد تخفیف |
| `flavor_chefs` | آشپزهای ما |
| `flavor_cart` | سبد خرید |
| `flavor_features` | **تازه:** چرا ما؟ (کارت‌های ویژگی) |
| `flavor_stats` | **تازه:** آمار (عدد + برچسب، مثلاً «سال تجربه») |
| `flavor_process` | **تازه:** مراحل سفارش یا رزرو (شماره‌دار) |
| `flavor_faq` | **تازه:** پرسش‌های متداول با `<details>`؛ بدون JavaScript |
| `flavor_price_list` | **تازه:** فهرست قیمت چاپی (نوشیدنی، منوی ویژه) |

قیمت‌ها در فهرست چاپی و آمار همان متنی است که شما وارد می‌کنید؛ ویجت هیچ عددی را محاسبه یا تغییر نمی‌دهد. قیمت محصولات منو همیشه از ووکامرس می‌آید.

## کنترل‌های ظاهری در تب «استایل»

هر ۱۷ ویجت Flavor بخش «ظاهر و سبک Flavor» را در تب **استایل** دارد. این کنترل‌ها مستقیماً اجزای داخل ویجت را تنظیم می‌کنند؛ از تب **پیشرفته** Elementor هم می‌توانید همچنان فاصله، حاشیه و تنظیمات عمومیِ کادر بیرونی ویجت را تغییر دهید.

- **رنگ‌های برند:** رنگ اصلی، تأکید، متن، متن کم‌رنگ، سطح و خطوط.
- **بخش و چیدمان:** پس‌زمینه و فاصلهٔ داخلی بخش، حداکثر عرض محتوا، تعداد ستون‌های شبکه و هم‌ترازی متن.
- **تایپوگرافی:** رنگ و تنظیمات تایپوگرافی عنوان و تنظیمات تایپوگرافی متن.
- **کارت و دکمه:** پس‌زمینه و حاشیهٔ کارت، گردی گوشه‌ها و رنگ پس‌زمینه/متن دکمهٔ اصلی.

فاصلهٔ داخلی، عرض محتوا، تعداد ستون‌ها، هم‌ترازی و گردی گوشه‌ها در اندازه‌های صفحهٔ دسکتاپ، تبلت و موبایل قابل تنظیم‌اند. CSS هر کنترل به همان ویجت محدود می‌شود؛ مقدارهای خالی هم دست‌کاریِ پیش‌فرض پوسته را کنار نمی‌زنند. **Elementor Pro لازم نیست.**

## قالب‌های آمادهٔ صفحه

فایل‌ها در `flavor/elementor/templates/` هستند:

- `flavor-home.json`: صفحهٔ نخست (هیرو، ویژگی‌ها، آمار، منوی امروز، نظرات، دعوت به سفارش)
- `flavor-about.json`: درباره ما (داستان، مراحل سفارش، آمار، آشپزها، گالری)
- `flavor-menu.json`: صفحهٔ منو (منوی غذا، فهرست نوشیدنی، پیشنهاد ویژه، پرسش‌های متداول)

### نصب یک قالب

1. Elementor را فعال کنید.
2. یک صفحهٔ جدید با Elementor بسازید.
3. در Elementor روی **Templates ← Import** (یا ⋮ ← Import Template) بروید.
4. فایل JSON را انتخاب کنید و در صفحه درج کنید.

متن‌ها نمونه‌اند؛ هر کدام را در ویرایشگر تغییر دهید.

## بازسازی قالب‌ها

اگر کنترل‌های یک ویجت را تغییر دادید، قالب‌ها را دوباره بسازید:

```bash
python3 dev-tools/elementor/build-templates.py
php tests/theme/test-elementor-widgets.php
```

تست بررسی می‌کند هر `widgetType` و هر کلید تنظیمات در ویجت واقعی وجود داشته باشد.

## همگام‌سازی Global Kit با توکن‌های Flavor

کلاس `Flavor\Elementor\Kit_Sync` توکن‌های طراحی Flavor را در کیت فعال Elementor می‌نویسد:

| مقدار Elementor | توکن Flavor |
|---|---|
| Global Colors: Primary / Secondary / Text / Accent | `primary` / `secondary` / `ink` / `accent` |
| Custom Colors: `flavor-bg`، `flavor-surface`، `flavor-surface-alt`، `flavor-muted`، `flavor-line` | `bg`، `surface`، `surface_alt`، `muted`، `line` |
| Global Fonts: Primary / Text | `font_heading` / `font_body` |

- همگام‌سازی بعد از هر ذخیرهٔ Customizer اجرا می‌شود.
- اگر کاربر یکی از این مقادیر را مستقیماً در Elementor تغییر داده باشد، Flavor آن را بازنویسی نمی‌کند و در گزارش به‌عنوان `skipped` ثبت می‌شود. آخرین مقدار نوشته‌شده در option با نام `flavor_elementor_kit_sync_state` نگه داشته می‌شود.
- `Kit_Sync::sync( true )` همهٔ کلیدها را به‌زور بازنویسی می‌کند.
- آیتم‌های سیستمی که کاربر از کیت حذف کرده دوباره ساخته نمی‌شوند؛ آیتم‌های `flavor-*` در صورت نبود اضافه می‌شوند.

**تست:** روی Elementor 4.3.4 واقعی در سایت آزمایشی بررسی شد: اجرای اول مقادیر را نوشت، اجرای دوم بدون تغییر بود، ویرایش دستی حفظ شد، و `force` آن را بازنویسی کرد. بقیهٔ گروه‌های کیت دست‌نخورده ماندند. `tests/theme/test-elementor-kit-sync.php` نگاشت را در برابر همهٔ پیش‌تنظیم‌ها بررسی می‌کند.

## آنچه هنوز انجام نشده

- **هدر، فوتر و صفحهٔ محصول:** تصمیمشان گرفته شده و پیاده است؛ بخش «تصمیم Theme Builder (R3-01 — گزینهٔ (ب))» را ببینید.
- **بازبینی بومی ترجمهٔ عربی:** همهٔ ۱۳۸۰ رشتهٔ کاتالوگ ترجمه و اعتبارسنجی فنی شده‌اند؛ بازبینی نهاییِ مترجم بومی هنوز انجام نشده است.
- **تست ویدیویی و نصب از کانال به‌روزرسانی:** انجام نشده.

## تصمیم Theme Builder (R3-01 — گزینهٔ (ب))

ماژول Theme Builder در Elementor رایگان وجود ندارد و فقط در نسخهٔ Pro است. ساختن یک ماژول موازی درون قالب، پرریسک و بی‌پایان بود؛ تصمیم پروژه گزینهٔ (ب) است: **هدر، فوتر و صفحهٔ تک‌محصول را خودِ Flavor می‌سازد، و Elementor Pro برای هیچ‌کدام از آن‌ها لازم نیست.**

| بخش صفحه | چه چیزی آن را می‌سازد | فایل مرجع |
|---|---|---|
| هدر، فوتر، نوار اطلاعیه، نوار دسترسی موبایل | چیدمان‌ساز داخلی و تنظیمات قالب | `flavor/inc/class-chrome-builder.php`، `flavor/inc/class-customizer.php` |
| صفحهٔ تک‌محصول: کارت، انتخاب‌های غذا، دکمهٔ سفارش | `Flavor\Product_Page` روی قلاب‌های خودِ ووکامرس | `flavor/inc/class-product-page.php`، `flavor/assets/css/ui-product.css` |
| بخش‌هایی که خودتان می‌چینید | ویجت‌ها و سه قالب آمادهٔ Elementor (نسخهٔ رایگان) | `flavor/elementor/` |

- **چیزی نصب نمی‌کنید.** افزونهٔ رایگانِ المنتور برای همان ویجت‌ها و قالب‌ها کافی است؛ Pro لازم نیست و هیچ بخشی از Flavor به آن وصل نیست.
- **چیزی قفل نمی‌شود.** هدر و فوتر از تنظیمات قالب می‌آیند، نه از یک قالبِ Elementor؛ پس با حذفِ المنتور هم صفحه خراب نمی‌شود. صفحهٔ تک‌محصول هم هیچ قالبِ ووکامرس را کپی نمی‌کند: فقط روی `woocommerce_before_add_to_cart_button` نوشته می‌شود، تا یک به‌روزرسانیِ ووکامرس آن را بی‌صدا از کار نیندازد.
- **انتخاب‌های غذا (مدیفایرها)** که در تب «غذا (رستوران مستقیم)» تعریف می‌کنید، از این نسخه در خودِ صفحهٔ محصول هم دیده می‌شوند. تا پیش از آن فقط در شیتِ منو قابل انتخاب بودند، یعنی مشتری‌ای که از جست‌وجو یا فهرست دسته‌بندی مستقیم به محصول می‌رسید راهی برای انتخاب نداشت و همان غذا با «اضافه‌ها» در رسید ثبت می‌شد. مبلغِ انتخاب‌ها در سبد خرید افزوده می‌شود، نه با محاسبهٔ جاوااسکریپت در صفحه.
- **خاموش‌کردن:** با `add_filter( 'flavor_product_modifiers_enabled', '__return_false' )`. گزینهٔ پنلی ندارد، چون فرمِ اصلیِ ووکامرس تنها راهِ قابل‌قبولِ افزودنِ محصولِ متغیر به سبد است و وقتی انتخاب‌گر خاموش شود همان فرم دست‌نخورده می‌ماند.
- **ادعای بازاریابی (R3-11):** هیچ‌جا — نه `README.md`، نه `flavor/readme.txt`، نه متن لیستینگ راست‌چین — عبارت «Theme Builder» به‌کار نرفته است و `tests/theme/test-product-page.php` در هر اجرا همین را بررسی می‌کند؛ اگر روزی پشتیبانی از Pro اضافه شد، همان تست نگهبانِ هم‌ترازی است.

## تست روی Elementor واقعی

تست یکپارچهٔ `tests/integration/real-elementor-smoke.php` با WordPress 7.1.3، WooCommerce 11.0.1 و Elementor 4.3.4 واقعی اجرا می‌شود. نتیجهٔ اجرای محلی اخیر: **۸۲ موفق، صفر ناموفق**.

- هر ۱۷ ویجت در مدیر واقعی Elementor ثبت می‌شوند؛ کنترل‌های واکنش‌گرای تب استایل نیز برای همه حاضرند.
- قالب‌های `flavor-home`، `flavor-about` و `flavor-menu` از طریق Elementor رندر می‌شوند.
- صفحهٔ آزمایشی هر ۱۷ ویجت را کنار هم اجرا می‌کند و نبود خطای PHP/جای‌نگهدار خطای Elementor را بررسی می‌کند.
- با محصول واقعی ووکامرس، خروجی ویجت منو نیز بررسی می‌شود.
- تست CSS تولیدشده را هم بررسی می‌کند: رنگ برندِ اختصاصی، تعداد ستون‌های واکنش‌گرا و فاصلهٔ داخلی بخش باید از کنترل‌های تب استایل به CSS صفحه برسند.

این تست در `.github/workflows/ci.yml` به نسخهٔ Elementor **4.3.4** پین شده است. برای اجرای محلی، WordPress آزمایشی با Flavor، WooCommerce و همین نسخهٔ Elementor لازم است:

```bash
php tests/integration/real-elementor-smoke.php --wp=/path/to/wordpress
```

تست آفلاینِ قرارداد ویجت‌ها نیز با `php tests/theme/test-elementor-widgets.php` اجرا می‌شود.
