# بازطراحی تخصصی دموها

آخرین به‌روزرسانی: ۱ اکتبر ۲۰۲۶

## وضعیت

هفت دموی قبلی حفظ شده‌اند. دموهای تکمیل‌شدهٔ جدید به کاتالوگ نصب یک‌کلیکی اضافه می‌شوند؛ صرف تعریف یک پوستهٔ رنگی به معنی وجود بستهٔ نصب نیست.

| دمو | برند نمونه | وضعیت |
|---|---|---|
| `juice-bar` | لیمو | تکمیل و تست شد |
| `dark-luxe` | — | در انتظار بازطراحی |
| `minimal-clean` | — | در انتظار بازطراحی |
| `cloud-kitchen` | — | در انتظار بازطراحی |
| `catering` | — | در انتظار بازطراحی |

### آبمیوه و اسموتی — لیمو

- هویت روشن و ارگانیک با سبز برگ، کرم و زرد مرکباتی؛ هدر، هیرو، کارت محصول، داستان برند، پیشنهاد شات، FAQ و فوتر اختصاصی.
- شش تصویر جدید محلی و بهینه‌شده؛ تصویر قبلی دمو در بخش داستان برند حفظ شده است.
- ۸ محصول نمونه، ۴ دستهٔ تصویردار، زمان آماده‌سازی، رسپی و اطلاعات نمونهٔ حساسیت غذایی.
- منوی منتخب از محصولات واقعی ووکامرس خوانده می‌شود؛ فیلتر دسته‌ها با وضعیت قابل‌خواندن برای صفحه‌خوان.
- سرویس بیرون‌بر و ارسال؛ بدون وعدهٔ رزرو میز، امتیاز مشتری ساختگی، تخفیف غیرفعال یا ادعای درمانی.

## نصب و شخصی‌سازی

۱. پوشهٔ `flavor` را به‌عنوان قالب و `flavor-core` را به‌عنوان افزونه نصب یا به‌روزرسانی کنید. ووکامرس باید فعال باشد.
۲. در **نمایش ← دموهای Flavor** بستهٔ موردنظر را درون‌ریزی کنید.
۳. نام، لوگو، تیتر و متن اصلی، رنگ‌ها، فونت و اطلاعات تماس در سفارشی‌ساز قابل تغییرند. بخش **صفحه اختصاصی دمو** تیترهای جدید، تصویر داستان برند و نمایش/پنهان‌سازی بخش‌ها را کنترل می‌کند.
۴. محصولات، قیمت‌ها و تصاویر محصول از مدیریت ووکامرس ویرایش می‌شوند. لینک کارت‌ها محصول واقعی را در صفحهٔ منو باز می‌کند؛ بدون تأیید کاربر چیزی به سبد اضافه نمی‌شود.
۵. منوی ساخته‌شده لینک‌های درون‌صفحه‌ای دارد. از مدیریت فهرست‌ها قابل تغییر است. روی صفحات داخلی، لینک‌ها به بخش مناسب صفحهٔ اصلی برمی‌گردند.

**هشدار:** نصب مجدد یک دمو محتوای برچسب‌خوردهٔ دموی قبلی و تنظیمات اختصاصی آن را بازنشانی می‌کند. صفحات و محصولات فاقد برچسب دمو پاک نمی‌شوند. برای ارتقای سایت فعال، ابتدا پشتیبان و محیط آزمایشی داشته باشید؛ درون‌ریزی را بی‌دلیل روی سایت زنده اجرا نکنید.

نام برند، تلفن، نشانی، ساعات، رسپی و قیمت‌ها محتوای نمایشی‌اند و باید قبل از انتشار واقعی اصلاح شوند. تصاویر جدید تولیدشده با هوش مصنوعی‌اند؛ فایل `ASSETS.md` هر بسته منشأ تصاویر را توضیح می‌دهد.

## معماری و سازگاری

- بسته‌های جدید: `flavor/inc/demo-packs/<slug>.php`.
- ترکیب صفحهٔ هر دمو: `flavor/template-parts/demos/<slug>.php`.
- پوستهٔ اختصاصی: `flavor/assets/css/skins/<slug>.css`.
- اجزای مشترک محدود به دموهای جدید: `class-bespoke-demos.php`، `bespoke-demos.css` و `bespoke-demos.js`.
- ۷ صفحهٔ قبلی همچنان از قالب‌های بازاریابی اصلی استفاده می‌کنند؛ فایل‌های CSS و تصاویر آن‌ها تغییر نکرده‌اند.
- فونت‌ها محلی‌اند: استعداد متغیر برای تیتر و وزیرمتن برای متن. نیاز به CDN یا فونت تجاری جدید نیست.
- نصب‌کننده عکس اختصاصی هر محصول را پشتیبانی می‌کند، تصاویر مشترک را دوباره وارد نمی‌کند، جدول‌های ووکامرس را با CRUD همگام می‌کند و از تکثیر فهرست و هیرو در نصب مجدد جلوگیری می‌کند.
- ناسازگاری قبلی `menu.js` با پاسخ `{success,data,meta,errors}` اصلاح شد. پاسخ‌های قدیمی خام نیز خوانده می‌شوند؛ قیمت ذخیره‌سازی ریال/تومان و گروه‌های انتخاب محصول طبق تنظیمات Flavor Core تبدیل می‌شوند. رابط API افزونه تغییر نکرده است.

## آزمون‌های قابل تکرار

بررسی بدون دست‌کاری پایگاه داده:

```bash
php tests/demos/catalog.php
find flavor -name '*.php' -print0 | xargs -0 -n1 php -l
node --check flavor/assets/js/menu.js
node --check flavor/assets/js/bespoke-demos.js
```

آزمون نصب، **فقط روی وردپرس دورریختنی** با `WP_ENVIRONMENT_TYPE=local` یا `development`:

```bash
FLAVOR_DEMO_QA=1 DEMO_SLUG=juice-bar wp eval-file /path/to/repo/tests/demos/import.php
```

آزمون مرورگر و دسترس‌پذیری:

```bash
cd tests/demos
npm ci
npx playwright install --with-deps chromium
SITE_URL=https://your-test-site.example/ npm test
```

خروجی پیش‌فرض داخل `.cache/demo-qa` است. با `QA_OUTPUT_DIR` قابل تغییر است. این تست به محصول واقعی ووکامرس، Flavor Core فعال و پیوندهای یکتای صحیح نیاز دارد؛ سبد آزمایشی می‌سازد اما پرداخت، ارسال پیامک یا ثبت سفارش انجام نمی‌دهد.

### نتیجهٔ بررسی فعلی

محیط: WordPress 7.1.2، WooCommerce 11.1.2، PHP 8.4.26، افزونهٔ همراه همین مخزن و SQLite Integration 3.0.2؛ مرورگر Chromium با Playwright 1.63.0.

- `juice-bar`: عبور از بررسی PHP/JavaScript، تصاویر و بستهٔ نصب، نصب مجدد، واکنش‌گرایی در عرض‌های ۳۲۰، ۳۹۰، ۷۶۸، ۱۰۲۴ و ۱۴۴۰، تست خودکار WCAG 2/2.1 A/AA در دسکتاپ و موبایل، فیلتر منو، FAQ، فوکوس و Escape در منوی موبایل، لینک محصول، افزودن صریح به سبد و ماندگاری سبد، و نمایش محصولات بدون JavaScript.
- تست خودکار جای ممیزی دستی کامل WCAG یا تست روی هاست/MySQL، درگاه پرداخت و ارسال واقعی را نمی‌گیرد. آن موارد در این بازطراحی ادعا نشده‌اند.
