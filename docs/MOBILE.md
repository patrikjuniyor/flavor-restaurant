# مستند فنی معماری و استقرار اپلیکیشن موبایل Flavor (نسخه ۱.۱.۰)
# Flavor Mobile Application — Technical Architecture & Deployment Guide

این سند، راهنمای جامع معماری، پیکربندی White-label، پروتکل‌های امنیتی، پیوندهای عمیق (Deep Links) و فرایند انتشار اپلیکیشن موبایل **Flavor** بر پایه فریم‌ورک فلاتر (Flutter) است.

---

## ۱. نقشه معماری و جریان داده‌ها (Data Flow Architecture)

```
┌────────────────────────────────────────────────────────┐
│                   UI / View Layer                      │
│   (Screens, Custom Widgets, RTL Directionality)        │
└───────────────────────────▲────────────────────────────┘
                            │ (Notifies State Changes)
┌───────────────────────────┴────────────────────────────┐
│               State Management Layer                   │
│   (Provider: Auth, Config, Menu, Cart, Order, Res)     │
└───────────────────────────▲────────────────────────────┘
                            │ (Calls Domain Methods)
┌───────────────────────────┴────────────────────────────┐
│                  Repositories Layer                    │
│   (Data Transformation, Local Caching, Error Handlers) │
└───────────────────────────▲────────────────────────────┘
                            │ (Executes HTTP Operations)
┌───────────────────────────┴────────────────────────────┐
│                    API Client Layer                    │
│   (Bearer Token Injector, Guest Cart Token, Rotation)  │
└───────────────────────────▲────────────────────────────┘
                            │ (Standard REST Envelope)
┌───────────────────────────┴────────────────────────────┐
│                Flavor Core REST API                    │
│              (/wp-json/flavor/v1/)                     │
└────────────────────────────────────────────────────────┘
```

## ۲. مشخصات ۲۶ قابلیت مشتری پیاده‌سازی شده در اپلیکیشن

1. **اسپلش اسکرین هوشمند (Splash Screen)**: بارگذاری اولیه تنظیمات، احراز هویت توکن‌های محلی و چک کردن اتصال اینترنت.
2. **برندینگ پویا (Restaurant Branding)**: تغییر داینامیک رنگ‌های اصلی و ثانویه، لوگو، فونت و استایل دکمه‌ها بدون نیاز به بیلد مجدد.
3. **صفحه اصلی (Home)**: بنر تخفیف، انتخابگر سریع شعب، پیشنهادات ویژه، دسته‌بندی‌ها، غذاهای محبوب و رزرو آنلاین.
4. **دسته‌بندی‌ها (Categories)**: فهرست افقی و فیلترهای چیپسی هوشمند با تعداد آیتم‌ها.
5. **منوی کامل (Menu)**: دسترسی به تمام اقلام بر اساس شیفت زمانی روز (صبحانه، ناهار، شام) و وضعیت موجودی شعبه.
6. **جزئیات کامل غذا (Product Details)**: اسلایدر تصاویر، کالری، زمان طبخ، آلرژن‌ها، برچسب‌های رژیمی و نظرات خریداران.
7. **جستجوی هوشمند (Search)**: تکمیل خودکار کلمات (Autocomplete)، جستجوهای ترند و فیلترهای رژیمی و قیمتی.
8. **شخصی‌سازی غذا (Product Customization)**: مدیفایرهای تکی (سایز پرس)، چندتایی (مخلفات)، درجه پخت، حذف مواد و یادداشت سرآشپز.
9. **سبد خرید (Cart)**: کنترل تعداد اقلام، حذف ردیف، نمایش ریز مدیفایرها و خلاصه صورتحساب.
10. **تسویه‌حساب (Checkout)**: انتخاب ۳ حالت دریافت سفارش (سالن / تحویل حضوری / پیک)، انتخاب میز یا آدرس، انتخاب درگاه پرداخت.
11. **مدیریت آدرس‌ها (Address Management)**: ثبت، ویرایش و ذخیره آدرس‌ها با لوکیشن و پلاک/واحد.
12. **تاریخچه سفارش‌ها (Order History)**: فهرست سفارش‌های قبلی با نشان‌های رنگی وضعیت، تاریخ شمسی و فاکتور.
13. **رهگیری زنده سفارش (Order Tracking)**: نمایش ۴ مرحله‌ای زمان‌بندی طبخ و ارسال با پولینگ خودکار وضعیت سرور.
14. **رزرو آنلاین میز (Reservation)**: انتخاب شعبه، تقویم جلالی، تعداد نفرات، بخش سالن/تراس و اسلات زمانی آزاد.
15. **سوابق رزرو (Reservation History)**: پیگیری وضعیت تأیید یا لغو رزروهای گذشته و آینده.
16. **پروفایل کاربری (Profile)**: نمایش مشخصات، تغییر نام، ایمیل، ترجیحات غذایی و سوئیچ حالت شب (Dark Mode).
17. **علاقه‌مندی‌ها (Favorites)**: ذخیره‌سازی محلی و لود سریع غذاهای مورد علاقه.
18. **کدهای تخفیف (Discounts)**: اعمال کوپن‌های درصدی یا مبلغی با پیام خطای محلی.
19. **باشگاه مشتریان (Loyalty)**: تبدیل امتیازات کسب‌شده به تخفیف ریالی/تومانی در سفارش.
20. **صندوق اعلان‌ها (Notifications)**: پیام‌های آماده شدن سفارش، تخفیف‌های مناسبتی و رزروها.
21. **درباره رستوران (Restaurant Info)**: تاریخچه، معرفی سرآشپز و تصاویر محیطی.
22. **ساعات کاری (Opening Hours)**: نمایش ساعات کاری ایام هفته و تعطیلات با نشان باز/بسته بودن.
23. **اطلاعات تماس (Contact)**: تماس مستقیم تلفنی با شعب و پشتیبانی.
24. **مسیریابی و نقشه (Location / Map)**: نمایش نشانی شعب و اتصال به اپلیکیشن‌های نقشه.
25. **احراز هویت دومنظوره (Authentication)**: ذخیره امن توکن‌ها در Keystore/Keychain و پشتیبانی هم‌زمان مهمان و کاربر لاگین‌شده.
26. **ورود با پیامک (OTP Login)**: فرمت استاندارد موبایل ایران (09xxxxxxxxx) و تایمر شمارش معکوس ارسال مجدد.

## ۳. پیکربندی پیوندهای عمیق (Deep Links & App Links)

| آدرس وب‌سایت | صفحه متناظر در اپلیکیشن موبایل | آرگومان ارسالی |
|:---|:---|:---|
| `https://restaurant.com/menu` | `MenuScreen` | — |
| `https://restaurant.com/product/123` | `DishDetailScreen` | `dishId: 123` |
| `https://restaurant.com/order/8520` | `OrderTrackingScreen` | `orderId: 8520` |
| `https://restaurant.com/reservation` | `ReservationScreen` | — |

## ۴. چرخه احراز هویت و امنیت توکن‌ها

1. هنگام لاگین، توکن‌های `access_token` (۷ روز) و `refresh_token` (۳۰ روز) دریافت و در `FlutterSecureStorage` (محیط سخت‌افزاری امن iOS Keychain و Android EncryptedSharedPreferences) ذخیره می‌شوند.
2. در کلیه درخواست‌ها، توکن در هدر `Authorization: Bearer <token>` تزریق می‌شود.
3. در صورت دریافت خطای ۴۰۱، کلاینت HTTP به صورت پشت‌صحنه و شفاف با ارسال Refresh Token توکن‌های جدید دریافت کرده و درخواست کاربر را بدون ایجاد وقفه مجدداً تکرار می‌کند.
4. در صورت ابطال توکن، کاربر به حالت مهمان منتقل شده و توکن‌های محلی پاکسازی می‌شوند.
