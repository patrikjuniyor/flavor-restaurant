# ارتقای رابط مشترک Flavor

شروع: ۲ اکتبر ۲۰۲۶. مبنا: `edd08b1`. هویت و ترکیب صفحهٔ اصلی ۱۲ دمو حفظ می‌شود؛ منطق سفارش، مبلغ و پرداخت همچنان در Flavor Core و ووکامرس است.

## مراحل اجرایی

| مرحله | دامنه | وضعیت |
|---|---|---|
| ۱ | پایهٔ رابط، صفحهٔ منو، جست‌وجو و پنل جزئیات غذا | تکمیل و تست شد |
| ۲ | سبد، ویرایش تعداد، روش دریافت و تسویه‌حساب | در حال اجرا |
| ۳ | ناوبری موبایل و تجربهٔ سفارش QR | در انتظار |
| ۴ | ورود، حساب مشتری و نمایش سفارش واقعی | در انتظار |
| ۵ | رزرو، شعبه‌ها، تماس، درباره، ۴۰۴ و حالت‌های خالی/خطا | در انتظار |
| ۶ | تنظیمات ظاهری معتبر، پیش‌نمایش و بررسی نهایی | در انتظار |

## قرارداد طراحی و ایمنی

- پالت، فونت و شخصیت هر پوسته به ارث می‌رسد؛ رنگ متن دکمه و متن فرعی برای خوانایی محاسبه می‌شود.
- اطلاعات محصول، قیمت، انتخاب‌ها، ظرفیت رزرو و وضعیت سفارش باید از دادهٔ واقعی خوانده شوند، نه تایم‌لاین یا امتیاز نمایشی.
- دیدن محصول، انتخاب شعبه و بازکردن پنل نباید خودکار غذا یا سفارش بسازد.
- رابط در عرض‌های ۳۲۰ تا ۱۴۴۰، با کیبورد، کاهش حرکت و حالت بدون JavaScript بررسی می‌شود.
- در تست‌ها پرداخت، پیامک واقعی و سفارش مشتری انجام نمی‌شود. تست‌های مخرب تنها با رضایت صریح `FLAVOR_DEMO_QA=1` روی وردپرس دورریختنی مجازند.
- توکن GitHub در فایل‌ها یا تنظیمات مخزن ذخیره نمی‌شود.

## آزمون‌ها

نتایج هر مرحله و دستورهای قابل تکرار در ادامهٔ همین سند تکمیل می‌شود. آزمون‌های دمو در `tests/demos` و آزمون‌های رابط مشترک در `tests/ui` قرار دارند.

### مرحلهٔ ۱ — نتیجه

منوی کارتی/فهرستی، دسته‌بندی چسبان با تعداد واقعی، جزئیات تصویری غذا، انتخاب‌های گروه‌بندی‌شده، قیمت نهایی و تعداد، راهنمای حساسیت غذایی، بازگشت فوکوس/فوکوس محدود و لینک محصول بدون افزودن خودکار تکمیل شدند. منوی بدون JavaScript واقعاً از ووکامرس رندر می‌شود. انتخاب نتیجهٔ جست‌وجو به جزئیات همان غذا در منو می‌رود.

آزمون واقعی وردپرس: پنج عرض ۳۲۰/۳۹۰/۷۶۸/۱۰۲۴/۱۴۴۰، منوی دسکتاپ/موبایل و پنل محصول بدون خطای خودکار WCAG، فیلتر/نمایش، Escape و بازگشت فوکوس، مبلغ تعداد، لینک محصول و سبد ماندگار عبور کردند. رنگ کنترل‌ها در هر ۱۲ پوسته بررسی شد.

```bash
php tests/ui/tokens.php
cd tests/ui && npm ci
npx playwright install --with-deps chromium
SITE_URL=https://your-disposable-wordpress.example/ UI_STAGE=1 npm test
```
