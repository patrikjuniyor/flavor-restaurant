# Flavor GitHub Updater — راهنمای نصب

## چیست؟
یک ابزار ساده که با یک دکمه در پنل وردپرس، **پوسته Flavor** و **افزونهٔ Flavor Core** را مستقیم از گیت‌هاب آپدیت می‌کند. هر دو از یک commit دانلود می‌شوند.

## نصب

### ۱. ساختن پوشهٔ mu-plugins
اگر پوشهٔ `mu-plugins` وجود ندارد:
```bash
mkdir -p wp-content/mu-plugins
```

### ۲. کپی فایل
```bash
cp dev-tools/flavor-github-updater.php wp-content/mu-plugins/
```

### ۳. تعریف توکن
در فایل `wp-config.php` خط زیر را اضافه کنید (قبل از `That's all, stop editing!`):
```php
define( 'FLAVOR_GITHUB_TOKEN', 'ghp_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx' );
```

### ۴. استفاده
- به پنل وردپرس → نمایش → **🔄 آپدیت Flavor** بروید.
- **«🔍 بررسی نسخهٔ جدید»** بزنید تا SHA آخرین کامیت را ببینید.
- برای هر هدفی که عقب باشد، دکمهٔ جداگانه ظاهر می‌شود: **«⬇️ آپدیت پوسته Flavor»** یا **«⬇️ آپدیت افزونه Flavor Core»**. اگر هر دو عقب باشند، **«⬇️ آپدیت هر دو»** هم هست.
- فایل‌ها مستقیم از گیت‌هاب دانلود و جایگزین می‌شوند. افزونه فقط وقتی آپدیت می‌شود که از قبل در `wp-content/plugins/flavor-core` نصب باشد؛ این ابزار افزونه را نصب نمی‌کند.

## نحوهٔ کار
- از GitHub API برای بررسی آخرین کامیت شاخهٔ `main` استفاده می‌کند.
- زیپ همان commit را دانلود و فولدرهای `flavor/` و `flavor-core/` را جایگزین نسخهٔ فعلی می‌کند.
- پیش از جایگزینی، نسخهٔ فعلی هر هدف موقتاً پشتیبان گرفته می‌شود. اگر کپی شکست بخورد، از پشتیبان برمی‌گردد.
- فایل‌هایی که در مخزن حذف شده‌اند، از روی نسخهٔ نصب‌شده پاک **نمی‌شوند** (فقط اضافه و بازنویسی می‌شود).
- هر ۱۲ ساعت خودکار بررسی می‌کند و اگر آپدیت موجود باشد، در نوار بالای وردپرس نشان می‌دهد.
- از `Theme_Upgrader` وردپرس استفاده نمی‌کند — مستقیم فایل‌ها را کپی می‌کند.

## ⚠️ هشدار
**این ابزار فقط برای محیط توسعه / staging است.** در سایت زندهٔ مشتری از بستهٔ رسمی نصب استفاده کنید.

## تنظیمات قابل تغییر
در فایل `flavor-github-updater.php` ثابت‌های زیر را مطابق مخزنتان تغییر دهید:
- `REPO_OWNER` — نام کاربری مالک مخزن
- `REPO_NAME` — نام مخزن
- `BRANCH` — شاخهٔ پیش‌فرض (`main`)
- `THEME_SLUG` — نام فولدر پوسته داخل مخزن (`flavor`)
- `PLUGIN_SLUG` — نام فولدر افزونه داخل مخزن (`flavor-core`)
