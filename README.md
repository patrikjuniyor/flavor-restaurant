# رستوران مستقیم — Flavor

قالب وردپرس **flavor** + افزونه همراه **flavor-core**.

محصول تجاری سفارش‌گیری رستوران برای بازار ایران (راست‌چین). وردپرس ۶.۴+، ووکامرس ۸.۵+، PHP ۸.۰+.

> این ریپو یک **monorepo** توسعه است. بسته‌های فروش جداگانه می‌مانند:
> `flavor/` قالب و `flavor-core/` افزونه.

## این محصول چیست؟

صاحب کافه یا رستوران یک سایت موبایل‌اول می‌گیرد که مشتری از آن:

1. منو را می‌بیند و با اندازه / تاپینگ / درجه پخت سفارش می‌دهد
2. با اسکن QR میز، سفارش سالن می‌دهد
3. بیرون‌بر یا ارسال به آدرس انتخاب می‌کند
4. با شماره موبایل و OTP وارد می‌شود
5. رزرو شمسی می‌کند

آشپزخانه سفارش را روی تبلت به‌صورت کانبان می‌بیند. پرداخت آنلاین از درگاه‌های ووکامرس (زرین‌پال، آیدی‌پی، …) است یا پای صندوق / هنگام تحویل.

## معماری

| بسته | مسئولیت | اگر حذف شود |
|---|---|---|
| `flavor` (قالب) | ظاهر، دمو، ویجت، دراور سبد، اسکیما | داده سفارش و شعبه سالم می‌ماند |
| `flavor-core` (افزونه) | منطق، دیتابیس، REST، آشپزخانه، QR، رزرو، OTP | قالب مثل یک قالب رستورانی معمولی باقی می‌ماند |

### تصمیم‌های قفل‌شده فاز ۱

- **ارز:** قابل تنظیم. پیش‌فرض ذخیره **ریال** + نمایش **تومان**.
- **محصول:** محصول ساده ووکامرس + ماژول مدیفایر (نه custom product type).
- **آشپزخانه:** لاجیک فقط در افزونه. دو ویو: `wp-admin` و `/kitchen-dashboard/`. قالب فقط skin.
- **تیکت آشپزخانه:** جدول ایندکس‌شده منبع حقیقت عملیاتی است. ووکامرس مالی و آیتم را نگه می‌دارد.

جزئیات: [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) و [`docs/DATABASE.md`](docs/DATABASE.md).

## نصب برای توسعه

1. وردپرس ۶.۴+ و ووکامرس ۸.۵+ را نصب کنید.
2. پوشه `flavor` را به `wp-content/themes/` کپی یا symlink کنید.
3. پوشه `flavor-core` را به `wp-content/plugins/` کپی یا symlink کنید.
4. ووکامرس را فعال کنید، سپس Flavor Core، سپس قالب Flavor را فعال کنید.
5. به **رستوران مستقیم → تنظیمات** بروید و شعبه پیش‌فرض را بسازید.

```bash
ln -s /path/to/flavor-restaurant/flavor       /path/to/wp/wp-content/themes/flavor
ln -s /path/to/flavor-restaurant/flavor-core  /path/to/wp/wp-content/plugins/flavor-core
```

## نیازمندی‌ها

- PHP 8.0+ (۸.۱ توصیه می‌شود)
- WordPress 6.4+
- WooCommerce 8.5+ با HPOS
- پسوندهای PHP: mysqli, json, mbstring
- برای QR در فاز ۲: `ext-gd` یا Imagick
