# رستوران مستقیم — Flavor

قالب وردپرس **flavor** + افزونه همراه **flavor-core**.

محصول تجاری سفارش‌گیری رستوران برای بازار ایران (راست‌چین). وردپرس ۶.۴+، ووکامرس ۸.۵+، PHP ۸.۰+.

> این ریپو یک **monorepo** توسعه است. بسته‌های فروش جداگانه می‌مانند:
> `flavor/` قالب و `flavor-core/` افزونه.

نسخه پایدار: **۱.۰.۰**

## این محصول چیست؟

صاحب کافه یا رستوران یک سایت موبایل‌اول می‌گیرد که مشتری از آن منو سفارش می‌دهد (سالن با QR، بیرون‌بر، ارسال)، با موبایل وارد می‌شود و رزرو شمسی می‌کند. آشپزخانه سفارش را روی تبلت می‌بیند.

## معماری

| بسته | مسئولیت |
|---|---|
| `flavor` | ظاهر، ۸ دمو، ویجت، دراور سبد، اسکیما |
| `flavor-core` | منطق، دیتابیس، REST، آشپزخانه، QR، رزرو، OTP |

اگر قالب عوض شود سفارش و شعبه می‌مانند.

## نصب توسعه

```bash
ln -s /path/to/flavor-restaurant/flavor       /path/to/wp/wp-content/themes/flavor
ln -s /path/to/flavor-restaurant/flavor-core  /path/to/wp/wp-content/plugins/flavor-core
```

ووکامرس → Flavor Core → قالب Flavor. پیوندهای یکتا را ذخیره کنید. از **نمایش → دموهای Flavor** یک دمو درون‌ریزی کنید.
